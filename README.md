# AVP Prompt Library

A growing prompt-engineering library for cinematic art, image generation, video, and creative experimentation.

## Purpose

This repository documents prompt frameworks, tested prompts, experiments, and lessons learned while improving AI-assisted visual creation.

The goal is not to collect the longest prompts. It is to understand which instructions actually improve composition, scale, atmosphere, lighting, anatomy, and visual storytelling.

## Core Framework

Start with six parts:

1. **Subject** — What is the main subject?
2. **Appearance** — What does it look like?
3. **Environment** — Where is it?
4. **Camera** — How does the viewer see it?
5. **Lighting / Mood** — What should the scene feel like?
6. **Avoid** — What should the model avoid?

See `frameworks/six-step-image-prompt.md` for the first framework.
